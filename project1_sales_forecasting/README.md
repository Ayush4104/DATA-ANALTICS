# Project 1: Fashion E-commerce Sales Analysis & Demand Forecasting

## Problem
A fashion e-commerce business wants to know: how are we performing, which categories
and brands drive revenue and margin, and what will demand look like over the next 6 months?

## Tools
Python, Pandas, NumPy, Matplotlib, Scikit-learn

## How to run
```
pip install -r requirements.txt
python generate_data.py     # creates data/orders.csv (~57k orders, 2 years)
python analysis.py          # prints insights, saves charts + CSVs in outputs/
```

## What it does
1. Builds revenue, profit, and margin columns from price, discount, quantity, cost
2. Calculates KPIs: total revenue, gross margin %, average order value, unique customers
3. Compares categories and brands on revenue and margin
4. Forecasts the next 6 months of revenue using Linear Regression (trend + month-of-year seasonality)
5. Back-tests on the last 6 months (MAPE about 3%)

## Key insights found
- Watches and Sneakers drive the most revenue; Sneakers have the highest margin (38%)
- T-shirts have high volume but the lowest margin (24%)
- Demand peaks in Oct-Nov (festive season) with an overall upward trend

## Resume bullets (pick 2-3)

- Built a Linear Regression demand-forecasting model with trend and seasonality, achieving ~3% MAPE on a 6-month back-test
- Identified high-revenue but low-margin categories and recommended focus areas for margin improvement
